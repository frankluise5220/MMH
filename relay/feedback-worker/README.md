# MMH Feedback Relay

This Cloudflare Worker is the project-owned fallback for MMH feedback emails.
It keeps the Resend API key on the server, sends only to the fixed project
mailbox, and limits each installation to one accepted submission every 30
minutes.

The MMH app tries the user's SMTP configuration first, then local Resend, and
uses this fallback only when both are unavailable or fail. If the user enters a
valid email address, it is passed as `Reply-To`; the verified project sender
remains the `From` address.

## Deploy

```bash
cd relay/feedback-worker
npm install
npx wrangler secret put RESEND_API_KEY
npm run deploy
```

The route in `wrangler.toml` publishes the worker at:

```text
https://feedback.floatingice.win/v1/feedback
```

The domain must be managed by the same Cloudflare account. `FEEDBACK_FROM` must
be a verified Resend sender. `FEEDBACK_TO` defaults to `mmh@floatingice.win`
and is fixed server-side; it cannot be changed by a client request.

## Local check

```bash
npm run typecheck
npm run dev
```

The health endpoint is `GET /health`. The feedback endpoint is
`POST /v1/feedback` and expects the `x-mmh-installation-id` header generated by
the MMH server.
